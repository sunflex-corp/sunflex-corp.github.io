# SUNFLEX 사이트 — 디자인 시스템 Phase 2 (다크 히어로 + 컬러블록 + 폰트/여백 재조정)

## 배경

Phase 1(토큰/버튼/헤더-푸터 모노크롬화)에 이어, 사용자가 방향을 크게 확장했다: Figma
`DESIGN.md`의 구조(컬러블록 섹션 리듬)는 유지하되, 무드는 SpaceX/Tesla의 다크·시네마틱·
기술적 정체성을 메인으로 삼고, 타이포그래피는 Figma식(웨이트로 위계, 가는 대형 헤드라인)으로,
여백은 Apple HIG + Tesla/SpaceX 스타일로 널널하게 재조정한다. 산업안전 장비 회사라는 도메인
특성상 "미션 컨트롤" 무드가 파스텔 에디토리얼보다 더 잘 맞는다는 판단.

브레인스토밍 과정에서 비주얼 컴패니언으로 5라운드에 걸쳐 히어로 섹션을 반복 검증했고(무드 →
타이포 → 여백/웨이트 → 카피), 전부 승인받았다. 이 문서는 그 결과를 구현 스펙으로 정리한다.

## 범위

**포함**: 전역 폰트/타이포 토큰, 전역 spacing 재조정, 헤더(블랙 배경 + 스크롤 시 자동 숨김),
홈페이지 히어로 섹션, 홈페이지 신규 컬러블록 섹션(3분할: 블랙/블루/화이트).

**제외 (Phase 3+)**: 회사소개/솔루션/문의/제품 페이지의 고유 레이아웃 재작업, 제품 카드 그리드
재설계, 상세 반응형 QA.

## 폰트

| 역할 | 폰트 | 비고 |
|---|---|---|
| 히어로/대형 디스플레이 헤드라인 | **Asta Sans** (구 42dot Sans), weight 500 | 42dot(현대차그룹 자율주행) 코퍼레이트 서체. OFL 라이선스, BI/CI 포함 상업적 이용 무료, 한글 완전 지원(직접 렌더링 검증함). 저장소: `github.com/42dot/Asta-Sans`. `brand/fonts/AstaSans-{Regular,Medium,Bold}.ttf`로 로컬 번들 |
| 영문/숫자 UI 텍스트(내비, 버튼, eyebrow 보조) | **Inter** | 가변 웨이트, 로컬 번들 또는 자체 호스팅 (외부 CDN 의존 최소화 위해 로컬 권장) |
| 한글 본문 | **Pretendard Variable** (기존 유지) | 이미 로컬 번들되어 있음. Asta Sans/Inter는 한글 본문에 쓰지 않음(Inter는 한글 미지원, Asta Sans는 디스플레이 전용으로 제한) |
| eyebrow/caption 라벨 | **JetBrains Mono** | 로컬 번들, 소문자·자간 살짝 넓게 |

Asta Sans는 **히어로/섹션 대형 타이틀에만** 적용한다 (본문·버튼·내비 텍스트는 기존대로
Pretendard/Inter). 과다 적용 시 오히려 위계가 흐려짐.

## 타이포 위계 원칙

- 웨이트로 위계를 표현: 헤드라인 500, 리드문 380, UI 텍스트 520 — 3단계로 제한
- 헤드라인은 무겁게(700)가 아니라 **크게(clamp 34px~64px) + 가늘게(500)** — Figma식
- 헤드라인 자간만 살짝 좁게(-0.01em), 본문은 기본 자간 유지 (가독성 우선)
- 한 화면(뷰포트)에 헤드라인 + 리드문 + CTA 2개 이상의 텍스트 블록을 두지 않는다 (정보 밀도 억제)

## 여백(Spacing)

Tesla/SpaceX 참고: 기존보다 전반적으로 널널하게.

- 히어로 내부 상단 패딩: 기존 ~40px → **120px**
- 컬러블록 내부 패딩: 24px → **40px**
- 컬러블록 사이 gap: 8px → **20px**
- 히어로-블록 섹션 사이 간격: 기존 `--section-gap`(72px) → 재검토, 최소 96px 이상으로

8px 기반 스케일(HIG 8pt 그리드 원칙과도 부합) 안에서만 값을 고른다 — 임의값 금지.

## 헤더

- 배경을 화이트(Phase 1) → **완전 블랙(#000)** 으로 재변경. 텍스트/로고/네비 링크는 화이트 계열로 대비
- **스크롤 다운 시 위로 슬라이드되어 사라지고, 스크롤 업 시 다시 나타남** (스크롤 임계값 80px,
  `transform: translateY(-100%)`, transition 0.28s ease — 비주얼 컴패니언에서 실제로 스크롤
  테스트해서 승인받은 그대로)
- `position: sticky` 유지, 새 스크롤 리스너를 별도 JS 파일로 추가 (기존 BaseLayout 스크립트를
  건드리지 않고 독립 모듈로)

## 홈페이지 히어로 (SOLAR IA 반영 후 갱신)

- 기존 구조(터널 사진 배경 + 궤도 애니메이션 위젯 + 헤드라인 + CTA 2개)는 유지 — **궤도
  애니메이션(orbit) 위젯은 건드리지 않는다**(Phase 2a에서 이미 4노드로 재구성됨), 손대는 건
  타이포/여백/eyebrow 스타일뿐
- eyebrow 텍스트는 이미 실제 사이트에 있는 "산업 안전 솔루션 기업, 썬플렉스" 그대로 — **카피
  자체는 변경 없음**, JetBrains Mono 스타일(소문자 유지, 자간)만 적용
- 헤드라인은 원래 "…오감을 제공합니다"였으나 Phase 2a에서 분류 체계가 오감(5)→SOLAR 4단계로
  바뀌었으므로, "오감" 표현을 "네 가지 감각" 또는 SOLAR 4단계를 가리키는 문구로 살짝 다듬는다
  (완전히 새 카피를 짓기보다, 이미 Phase 2a에서 회사소개 페이지에 적용된 "하나의 현장, 네 가지
  감각" 표현과 통일감 있게 맞춘다) → Asta Sans 500, 위 타이포 위계 적용
- CTA 2개(제품 살펴보기 / 안전 위험성 평가) → Phase 1에서 이미 블랙 필/고스트 처리됨, 그대로 유지

## 홈페이지 신규 컬러블록 섹션 (SOLAR IA 반영 후 갱신)

히어로 바로 아래에 **4분할** 그리드 섹션을 새로 추가한다 (현재 홈페이지엔 없음, Figma 구조
도입). Phase 2a에서 분류가 정확히 4단계로 정리됐으므로 "5개 중 3개" 같은 어색한 발췌 없이
전부 자연스럽게 들어간다:

- 감지(블랙) / 경보(SUNFLEX 블루) / 대응(진한 톤 블록) / 기록(화이트), 각각 eyebrow + 타이틀
- 콘텐츠는 이미 Phase 2a에서 재구성된 `company/index.html`의 sense-explorer 4개 패널 문구를
  그대로 재사용 — 새 카피 창작 금지 (`01 DETECT 시각·관제`→"사람이 놓친 순간까지, 현장의 눈이
  멈추지 않도록" 등, 기존 `.sense-explorer__positioning`/패널 헤딩 텍스트 재활용)
- 각 블록은 해당 `/solutions/{detect,alert,respond,record}` 페이지로 링크 (Phase 2a에서 이미
  존재하는 경로)

## 검증

- 로컬 서버로 홈페이지 렌더링, 헤더 블랙 배경 확인, 스크롤 시 헤더 숨김/재등장 확인
- Asta Sans가 실제로 로드되어 한글이 정상 렌더링되는지 확인 (폴백 폰트로 깨지지 않는지)
- 모바일(375px)/태블릿(768px) 뷰포트에서 히어로·컬러블록이 깨지지 않는지 스크린샷 확인
- 다른 61개 페이지는 Phase 2에서 건드리지 않으므로, 헤더 블랙 배경 변경이 전역 적용되는 만큼
  제품 상세 페이지 1곳도 헤더가 정상(블랙, 스크롤 숨김)인지 샘플 확인
