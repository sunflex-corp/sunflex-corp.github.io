# 이동식 CCTV 편집 개편

2026-09-20. Chrome의 보이는 창에서 Apple 한국 페이지를 Page Down으로 끝까지 관찰했다.

## 참고 자료와 적용
- https://www.apple.com/kr/macbook-pro/ : 히어로, 하이라이트 레일, 제품 탐색, 칩별 소개, 칩 상세 모달(직접 열고 닫음), AI, 배터리, macOS, 연속성 탭, 디스플레이, 카메라, 포트, 보안, 업그레이드, 구매/환경/각주/푸터까지 확인. 핵심은 한 장면당 한 메시지, 제품 이미지와 설명의 근접성, 상세 정보의 점진적 공개. 문구나 Apple 이미지는 복사하지 않음.
- https://www.apple.com/kr/mac-mini/ : 히어로부터 전후면/치수, 책상 사용 장면, 칩/작업별 탭, AI, macOS, 연속성, 액세서리, 업그레이드, 비교/환경/푸터까지 확인. 작은 하드웨어의 물리적 특성을 큰 이미지와 인접 설명으로 다루는 방식 참고.

## 진단과 수정
1. S/M/L 선택 뒤 같은 분류가 지지 구조와 마지막 사진에서 다시 등장. 구조 설명을 해당 모델의 펼침 영역으로 이동하고, 설치 조건·추가 사진은 독립된 네이티브 details로 제공.
2. 이동 전후 도식은 빈 상자와 분리된 레이블로 흐름을 이해하기 어려웠음. 작업면 확인 → 담당자 재설치 → 영상 확인의 3단계 사진 패널로 변경. 조작 가능한 탭에 클릭·방향키·Home/End 지원.
3. 큰 제목과 긴 설명이 반복돼 위계가 약했음. 제목 상한과 본문 폭 제한, 핵심 과정은 어두운 장면으로 구분. 모바일 모델표는 한 화면에 맞춤.
4. 애니메이션은 opacity/transform 진입 효과, 기존 히어로 제품 펼침과 모델 선택 효과 유지. reduced-motion에서 새 전환 제거. 대형 필터나 지속적인 JS 렌더 루프 추가 없음. 4K FPS 실측을 뜻하지 않음.

제품 사실, 출처 이미지, 앵커를 모두 유지하는 생성기 검증 적용. 사진은 이미 프로젝트에 있던 현장 연출 에셋 사용. 원본 제품 사진에 없는 기능/수치 추가 없음.

## 시각 검수
Chrome 데스크톱에서 세 단계 사진과 클릭/방향키 전환 확인. 390px/768px 프레임에서 첫 화면부터 푸터까지 820px 간격으로 내려보며 검수. 실기기 Safari/Android 검수는 수행하지 않음.
