# Product presentation components

The 48 product pages share layout components generated by `scripts/product_revision.py` and visual fragments from `data/product-infographics.json`. Product facts and section anchors remain source-controlled. Synced project references are not modified.

## Component contract

- One content container: maximum 1120 px, desktop side inset 40 px, mobile side inset 20 px.
- Spacing tokens: 8, 12, 16, 24, 32, 48 px. Section spacing 64–96 px.
- Media radius 16 px; card radius 24 px; large story media 32 px, 24 px on mobile.
- `data-highlight-card=feature` requires an image and uses media/title/content slots. Text-only cards use `detail` and cannot inherit the old first-item mosaic placement.
- Detail cards share padding, title size, icon size and metric/unit baselines. An odd final text card spans the grid. Mobile is one column.
- Glass-inspired content surfaces use a restrained translucent gradient, edge highlight and static shadow. Repeated backdrop blur is omitted to avoid unnecessary compositing for static content.
- Product benefits use equal columns above 760 px. Each panel retains its own natural content height. A long scene does not stretch the backgrounds of every other scene.
- Infographic headings/captions remain HTML. Diagram-specific styles are scoped through the product section and scene attribute so generic icon rules cannot reduce a full diagram to 40 px.
- Photographs are not transformed inside a square clipping figure; that previously hid their intended rounded corners.

## Reference mapping

These are design references, not a claim of platform certification or pixel-for-pixel imports.

- [shadcn/ui Card](https://ui.shadcn.com/docs/components/base/card): separate media/header/content roles and shared spacing variables. Adapted to the site's existing static HTML generator without introducing a React runtime.
- [Material 3 cards](https://m3.material.io/components/cards/guidelines): grouping related content and distinguishing card roles.
- [Apple HIG Layout](https://developer.apple.com/design/human-interface-guidelines/layout), [Typography](https://developer.apple.com/design/human-interface-guidelines/typography), [Materials](https://developer.apple.com/design/human-interface-guidelines/materials): hierarchy, readable content and restrained material treatment. HIG does not prescribe these SUNPLEX web radius values.
- [Toss Post](https://tossmini-docs.toss.im/tds-mobile/components/post/): clear title/body hierarchy for Korean content.
- Figma library search located Material 3 Horizontal/Stacked Card and Simple Design System Card/Product Info Card. Instance import was blocked by the connected Starter plan MCP rate limit; no Figma geometry measurement or imported-instance implementation is claimed.

## Review and rebuild

Generate product pages with `generate-solar-site.py`'s `detail()` entry point, then run `scripts/apply-product-infographics.py` so visual fragments and stylesheet cache hashes are current.

Infographic refinement utilities apply in this order when rebuilding those fragments: examples, compositions, bodycam, context, signal. JSON is the committed source of truth; do not run a generic draft exporter over the reviewed fragments.

Checks: `test-product-infographics.py` (exact source/anchor preservation except explicitly mapped copy), `test-infographic-cascade.py` (includes fragment styles), `test-product-revision.py` (card roles and stylesheet order), and `test-product-flow.cjs` (keyboard/reduced motion/overflow reading behavior). They supplement actual browser inspection; they do not prove visual quality or real-device performance.
