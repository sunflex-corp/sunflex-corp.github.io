# 제품별 착용·사용 장면 교체

## 문제와 결정

안전모·장갑을 나열한 context-safety-preparation 이미지가 5개 제품 페이지의 6곳에 재사용되어 제품의 외형, 착용 위치, 조작 방식이 드러나지 않았다.

검토한 대안은 제품 단독 사진 확대, 범용 작업장 소품 배치, 실제 상품 사진을 참조한 착용·사용 장면이었다. 기존 제품 사진 갤러리는 유지하고, 설명 카드에는 세 번째 방식을 적용했다.

| 제품 | 교체 위치 | 보여주는 내용 |
| --- | --- | --- |
| 안전모 응급호출·위치알림 | 제품 강점 01 | 측면 원형 버튼을 누르는 동작 |
| 스마트 헬스케어 심박수밴드 | 제품 강점 01, band-functions | 손목에 착용한 밴드와 스트랩 조절 |
| 근력보조 웨어러블 슈트 | 제품 강점 01 | 등에 착용한 보조 장비와 작업대에서의 자재 취급 |
| 스마트 에어백 | 제품 강점 01 | 미전개 조끼의 착용 상태와 허리 버클 |
| 스마트 안전모 | 제품 강점 01 | 측면 모듈과 턱끈 |

새 이미지는 실제 제품 사진을 참조하여 생성한 래스터 이미지다. Blender 렌더 또는 편집 가능한 3D 모델이 아니다. 새 3D 지오메트리는 만들지 않았다. 제품의 구성과 사용 맥락을 설명하는 예시이며 설치 실적 사진이나 성능 검증 사진으로 사용하지 않는다.

출처 사진, 전체 생성 프롬프트, 원본 생성 파일명, 웹 자산 해시는 data/product-scene-overrides.json에 기록했다. 심박 수치, 에어백 전개 형태, 모터·로봇 부품, 위치 화면처럼 원본에서 확인할 수 없는 기능 표현을 추가하지 않았다.

## 검증

- 기존 이미지 사용 현황: 5페이지 6곳. 적용 후 제품 HTML에서 기존 이미지 참조 0건.
- 새 이미지 5종, 각각 1536 × 1024, WebP 126~192 KB.
- 제품 사진과 생성 결과를 비교하여 밴드 형태, 버튼 위치, 보조슈트 등판, 조끼 버클·반사띠, 안전모 모듈·턱끈을 육안 확인.
- 제품 설명·링크·기존 상품 사진·01/02/03 마크업과 스크립트는 유지. 변경된 이미지·캡션 외 DOM 비교 통과.
- 재생성 경로에도 교체 장면 적용. 같은 적용 작업을 반복해도 결과 유지.
- test-product-scenes.py 및 test-product-navigation.cjs 통과.
- Chrome 모바일 390 × 844에서 5페이지의 카드·이미지 확인. 가로 넘침 없음.
- 모바일 심박밴드 스크롤 01 → 02 → 03 전환 확인.
- 기본 데스크톱 화면에서 심박밴드 카드와 상세 설명 이미지 로드 확인.

## 버튼 위치 정정

사용자의 실제 제품 설명에 따라 응급호출 버튼 위치를 전면에서 측면으로 정정했다. 측면 버튼을 누르는 착용 장면으로 다시 생성하고 이미지·대체 텍스트·원본 프롬프트를 함께 교체했다.
