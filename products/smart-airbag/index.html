스마트 에어백 · 추락위험 대응

작업복 위에 더하는 충격 완화.

  1. 착용 보호

    몸 가까이 준비하는 충격 완화.

    착용형 에어백으로 머리·목·척추 주변의 충격을 줄이는 데 활용합니다. 작업 조건에 맞는 용량과 착용 상태가 중요합니다.

    관련 구성 자세히 보기 ↗

  2. 감지·전개

    설정 기준의 움직임에 반응합니다.

    6축 IMU의 감지 신호에 따라 내장 CO₂ 가스로 에어백이 전개됩니다. 감지 기준과 사용 조건을 확인해 적용합니다.

    관련 구성 자세히 보기 ↗

  3. 운영 점검

    착용 전부터 사용 뒤까지, 상태 확인.

    지급할 때 외관과 착용 상태를 확인합니다. 전개나 이상이 발생하면 작업자 상태를 확인하고 장비를 점검·관리합니다.

    관련 구성 자세히 보기 ↗

추락이 시작되는 짧은 사이

착용하는 충격 완화 장비.

추락 상황에서는 몸을 보호할 시간이 짧습니다. 스마트 에어백은 센서가 설정 기준의 움직임을 감지하면 내장 가스로 전개돼, 머리·목·척추 주변에 가해지는 충격을 줄이도록 설계된 착용 장비입니다.

0.2s
  1. 감지

    6축 IMU가 설정 기준의 움직임을 확인

  2. 전개 시작

    내장 CO₂ 가스로 0.2초 이내 전개

  3. 감싸기

    머리·목·척추 주변을 감싸 몸에 가는 충격을 저감

한 벌의 장비가 하루를 지나는 흐름

감지 신호에 따라 펼쳐지는 에어백.

작업 전에 지급·착용 상태를 확인하고, 사용 후에는 회수·점검 이력을 남깁니다. 전개한 장비는 정해진 관리 절차에 따라 확인합니다.

  1. 01

    작업 전 지급·착용

    작업반장은 지급 장비의 외관과 착용 상태 확인

  2. 02

    작업 중 추락 감지

    6축 IMU가 설정 기준의 움직임 감지

  3. 03

    0.2초 이내 전개

    내장 CO₂ 가스로 에어백 전개 시작

  4. 04

    작업 중지·상태 확인

    전개 또는 이상 신호가 발생하면 작업을 멈추고 작업자 상태와 장비 확인

  5. 05

    작업 후 회수·격리·기록

    작업 뒤 장비를 회수하고 전개·이상 내역과 정비 결과 기록

작업자와 장비가 맞도록

작업 조건에 맞는 용량과 착용 상태.

70L · 45L · 35L전개 용량

머리·목·척추 주변을 감싸는 전개 형태와 용량 선택, 착용 적합성은 작업 인원과 구간에 맞춰 고를 수 있습니다.

지급과 착용 확인, 작업 중 감지와 전개, 작업자 상태 확인, 회수와 기록까지 하루의 흐름을 그대로 따라갑니다.

0.2s이내 전개 시작

머리·목·척추 주변을 감싸는 전개

부풀어 오른 에어백이 충격에 약한 머리와 목, 척추 주변을 감쌉니다.
