연결이 닿아야. 현장도 보이니까.

01

음영 구간

정보가 필요한 작업 구간까지.

터널 등 통신이 약한 구간을 살펴 무선망을 구성합니다. 영상과 도면을 확인해야 하는 위치부터 검토합니다.

관련 구성 자세히 보기 ↗
02

메시 연결

무선 AP를 이어, 연결 범위를 넓히고.

구간 안의 무선 AP를 연결해 정보가 지나갈 경로를 구성합니다. 현장 구조와 연결 상태를 함께 확인합니다.

03

자료 확인

작업자와 관리자가 필요한 정보를 주고받도록 연결 환경을 마련합니다. 실제 작업 위치에서 수신 상태를 확인합니다.

현장에 맞는 구성

도입 전에 확인할 세 가지.

설치할 곳과 운영 방식을 함께 살펴보세요. 상담할 때 아래 조건을 알려주시면 구성을 검토하는 데 도움이 됩니다.

  2. 02전원·장애물

제품 상세

구성과 운영, 더 자세히.

제품 구성부터 설치 조건까지, 아래에서 차례로 확인하세요.

터널 안 정보가 이어지는 경로

통신 음영 구간으로 넓히는 무선망.

  1. 01

    통신 음영구간

    터널 안, 사진과 영상·도면을 다시 확인하기 어려운 곳을 파악

  2. 02

    메시 네트워크

    구간 안의 무선 AP를 이어 정보가 지나갈 경로를 구성

  3. 03

    확인 화면

    현장 밖 또는 관리 화면에서 필요한 정보와 연결 상태를 확인

무선 AP를 연결해 통신 음영 구간에 무선망을 구성합니다. 작업 구간에서 사진·영상·도면을 주고받고 연결된 현장 장비의 정보를 확인할 수 있습니다.

  • 음영구간 · 메시 노드 · 확인 화면

입구를 지나면

작업 구간으로 이어지는 무선망.

터널 안에서 사진을 보내거나 CCTV 화면을 확인할 때 연결이 끊기면 일을 잠시 멈추게 됩니다. 메시 네트워크로 무선 AP를 연결해 통신이 필요한 구간에 사진·영상·도면과 장비 정보를 전달합니다.

같은 신호, 다른 확인

작업자와 관리자가 함께 보는 영상과 도면.

01

현장 관리자

작업 중 필요한 영상·도면과 확인 화면을 결정

02

통신 담당자

신호가 끊기는 지점과 네트워크 연결 흐름을 확인

03

안전관리자

CCTV와 안전장비에서 확인해야 할 정보를 정리

현장에 맞춰 잇는 정보

사진과 영상, 도면을 작업 구간으로.

무선망을 정보가 필요한 자리에 맞춰 세우면 현장 안에서 무엇을 봐야 하는지도 한결 또렷해집니다.

  • 사진·동영상과 CCTV
  • 도면을 보는 현장 화면
  • WiFi 기반 연결 장비

한눈에 보는 강점

왜 통신 음영구간 무선 네트워크망 구성을 고를까요?

현장 장비를 무선망으로

CCTV와 연결 장비가 하나의 무선망으로 묶입니다.

끊기던 구간까지, 정보가 이어집니다

현장 관리자와 통신 담당자, 안전관리자가 같은 신호에서 각자 필요한 정보를 확인하고, 끊기지 않도록 정보를 전달합니다.

메시네트워크로 연결

무선 AP를 연결해 통신이 필요한 음영 구간에 네트워크를 구성합니다.

도면과 영상을 그 자리에서

터널 안 작업 구간에서도 사진·동영상·도면을 확인할 수 있도록 무선망을 구성합니다.

WiFi 장비를 현장 무선망에 연결

WiFi 기반 현장 장비를 무선망에 함께 연결합니다.
