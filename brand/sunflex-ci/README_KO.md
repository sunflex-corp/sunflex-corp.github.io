# SUNFLEX / SOLAR 수정 패키지 v1.1

## 핵심 변경
- SOLAR 영문: 생성 이미지의 굵고 넓은 인상을 기준으로 고정 벡터 레터링 제작.
- SUNFLEX 영문: 이미지에 없는 U/N/F/E/X를 같은 조형 원리로 새로 설계.
- 한글 회사 CI와 한글 솔루션 설명: 기존 아웃라인 유지. 새 폰트로 교체하지 않음.
- 앱 아이콘 내부 심벌: 중심·배경·곡률 유지, 기존 대비 선형 12% 확대.
- 라인업: 와이드형 / 시스템: 모듈형 / 솔루션: 세로형. 공통 가로형도 별도 제공.

## 서체에 대한 정확한 구분
첨부된 원본은 생성 이미지입니다. 원본 폰트 파일이나 조판 메타데이터가 없으며,
정확한 서체명을 특정할 근거가 없습니다. 이번 작업을 IBM Plex, Inter 또는 Helvetica를
찾아낸 것으로 해석하면 안 됩니다. SOLAR Reference Lettering은 본 작업의 내부 자산명이며
실재 배포 폰트 이름이 아닙니다. S와 O는 참조 이미지를 베지어 경로로 변환했고,
L/A/R은 직선·곡선을 정돈했으며 SUNFLEX에 필요한 나머지 글자는 새로 구성했습니다.
전체 알파벳을 입력할 수 있는 폰트를 제작한 것은 아닙니다.

기성 서체 비교용 후보: Inter Display Black 900. 이것은 근접한 방향의 비교 대상일 뿐
이미지의 실제 서체라고 확인된 것이 아닙니다. 공식 자료: https://rsms.me/inter/

## 색상과 형식
Primary: 기존 파랑 그라데이션 심벌 + 잉크색 영문/한글.
Flat: 기존 인디고 #4351D8 + 잉크 #0B1730.
Ink: 잉크 단색. White: 흰색(투명 배경이라 흰 화면에서는 보이지 않음).
앱 아이콘은 의도된 배경색을 포함합니다. 그 외 개별 PNG는 투명 배경입니다.
모든 개별 로고 SVG/PDF 글자는 벡터 경로이며 외부 웹폰트 로딩이 필요하지 않습니다.
EPS는 그라데이션을 제외한 단색/플랫 버전에 제공합니다.
검토 PDF 1쪽에는 비교를 위해 원본 이미지의 일부가 들어 있으므로 그 부분은 래스터입니다.
폰트 파일, 설치용 글꼴, 네이티브 Illustrator .ai 또는 네이티브 Figma .fig 파일은 포함하지 않습니다.
SVG와 PDF는 편집 가능한 벡터 호환 파일입니다.
